# Tip Calculator

Asks for a bill and tip %, then prints the tip and total to 2 decimal places. Bad input gets a friendly message, not a crash.

Run: `python tip_calculator.py` (Python 3.8+, no installs)
Test: `python -m unittest`

Example:
```
Bill amount: 100
Tip percentage: 15
Split between how many people? 1
Tip (15%): 15.00
Total: 115.00
```
